## Project Overview

This repository contains the source code for the Thornwood Bakery website, developed as a Proof of Evidence (PoE) across three parts for the Web Development module. Thornwood Bakery is a hypothetical artisan bakery based in Melville, Johannesburg.

The project is built using pure HTML5, CSS3, and vanilla JavaScript – no frameworks or libraries are used.

---

## Website Goals and Objectives

- Provide Thornwood Bakery with a permanent, searchable web presence to replace reliance on Instagram alone.
- Generate custom cake order leads through a dedicated enquiry form.
- Communicate product ranges, pricing, and trading hours clearly to reduce phone enquiries.
- Deliver a mobile-first, responsive, and accessible website that works across all major browsers.

---

## Key Features and Functionality

- Five fully linked HTML pages with consistent navigation.
- Mobile-responsive layout using CSS Grid and media queries.
- Mobile hamburger navigation toggle (JavaScript).
- Enquiry form with client-side validation (name, email, phone, order type, date, message).
- Contact form with client-side validation.
- Two store locations with embedded Google Maps on the contact page.
- Semantic HTML5 structure (header, nav, main, section, article, footer).
- CSS custom properties (variables) for consistent theming.
- Commented code throughout HTML, CSS, and JavaScript files.
